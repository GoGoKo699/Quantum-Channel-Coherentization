# Scientific reading route

The question is whether ordinary uses of an unknown physical channel can supply coherent access to its Liouville matrix, and what dimension cost that conversion necessarily incurs.

| Step | Authoritative account |
| --- | --- |
| Fix the input interface, vectorization, target and norm convention | [Model](model.md) |
| Build the mixed programs and evaluate their collision variance | [Evolution compiler](collision-compiler.md) |
| Obtain a complete exact block unitary with controlled error | [Block encoding](block-encoding.md) |
| Extract an unknown inverse and prove the dimension obstruction | [Dimension lower bound](dimension-lower-bound.md) |
| Account for channel uses, known gates, synthesis and memory | [Resources](resources.md) |
| See unitary and finite-noise consequences | [Examples](examples.md) |
| Understand the matching regime and its limits | [Interpretation](interpretation.md) |
| Check inheritance and the closest operational comparisons | [Related work](../references/RELATED_WORK.md) |
| Reproduce the finite diagnostics | [Verification](../verification/README.md) |

The full analytical contribution is organized by topic here. Finite diagnostics exercise the formulas and conventions; the written proofs establish the all-channel claims.
